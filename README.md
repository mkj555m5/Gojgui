# Gojgui Pro — لوحة تحكم استضافة احترافية

لوحة تحكم استضافة متكاملة تدعم **Python** و **Node.js** مع نظام حصص (رام + مساحة) وإدارة ملفات شاملة.

## ✨ المميزات

### 👑 لوحة المسؤول
- إنشاء حسابات بمواصفات مخصصة (رام + مساحة تخزين) مع سلايدرز وأزرار اختيار سريع
- تعديل حصص أي مستخدم في أي وقت (رام / مساحة / كلمة المرور)
- تاب خاص بالأدمن لتخصيص رامات ومساحة حسابه ثم الدخول للوحة الاستضافة مباشرة
- مراقبة جميع خوادم جميع المستخدمين مع إيقاف أي خادم فوراً
- إحصائيات النظام الحية (CPU / رام / قرص / بيئات التشغيل)
- بحث في المستخدمين وتصدير بياناتهم

### 🚀 الاستضافة
- خوادم **Python** (requirements.txt + pip install من الواجهة)
- خوادم **Node.js** (package.json + npm install من الواجهة) مع ملفات بداية جاهزة
- كونسول حي لكل خادم مع CPU / رام / IP / حجم الخادم
- تشغيل / إيقاف / إعادة تشغيل

### 🛡️ نظام الحصص
- حد رام لكل مستخدم: مراقبة تلقائية لكل عملية — عند التجاوز يتم إيقافها فوراً مع رسالة في السجل
- حد مساحة تخزين لكل مستخدم: مفروض على الرفع والحفظ والنسخ وفك الضغط
- الأدمن بلا حدود افتراضياً (-1) ويمكنه التخصيص

### 📁 إدارة ملفات شاملة
- مجلدات فرعية كاملة مع مسار تنقل (Breadcrumb)
- رفع ملفات متعددة بالسحب والإفلات
- **فك ضغط تلقائي** بعد الرفع (ZIP / TAR / TAR.GZ / TAR.BZ2 / XZ / 7Z / RAR)
- فك ضغط يدوي بزر مخصص + ضغط المحدد في ZIP
- تحميل ملف أو مجلد كامل (يضغط تلقائياً)
- نسخ / نقل / تكرار / إعادة تسمية / حذف فردي أو جماعي
- محرر أكواد مباشر (Ctrl+S للحفظ)
- تثبيت المكاتب بزر واحد (pip / npm)

### 📱 متجاوب بالكامل
- تصميم متجاوب للهواتف (تابات سفلية ثابتة، أزرار كبيرة للمس، الجدول يتحول لكروت)
- دعم viewport + theme-color

## 🔐 التشغيل

```bash
pip install -r requirements.txt
python3 app.py
```

الحساب الرئيسي: `Ziad555` / `Ziad555` (غيّرها فوراً من `app.py`)

### النشر على Vercel
`vercel.json` يشير إلى `bot.py` (نسخة مطابقة من `app.py`)
