# Gojgui Pro — لوحة تحكم استضافة احترافية

لوحة تحكم استضافة متكاملة تدعم **Python** و **Node.js** مع نظام حصص (رام + مساحة)، إدارة ملفات شاملة، **كونسول تفاعلي** (إرسال نصوص وأوامر للخوادم)، وتصميم متجاوب بالكامل للهواتف (PWA).

## ✨ المميزات

### 👑 لوحة المسؤول
- إنشاء حسابات بمواصفات مخصصة (رام + مساحة تخزين) مع سلايدرز وأزرار اختيار سريع
- تعديل حصص أي مستخدم في أي وقت (رام / مساحة / كلمة المرور)
- تاب خاص بالأدمن لتخصيص رامات ومساحة حسابه ثم الدخول للوحة الاستضافة مباشرة
- مراقبة جميع خوادم جميع المستخدمين مع إيقاف أي خادم فوراً
- إحصائيات النظام الحية (CPU / رام / قرص / بيئات التشغيل)

### 🚀 الاستضافة
- خوادم **Python** (requirements.txt + pip install من الواجهة)
- خوادم **Node.js** (package.json + npm install من الواجهة) مع ملفات بداية جاهزة
- كونسول حي لكل خادم مع CPU / رام / IP / حجم الخادم
- **🖥️ طرفية حقيقية (PTY)**: الخوادم تعمل داخل Pseudo-Terminal حقيقي (`TERM=xterm-256color`) — ألوان ANSI كاملة تلقائياً (كل الأدوات تكتشف أنها داخل ترمينال)، أشرطة تقدم حية، ورموز/إيموجي بدون تشويه
- **🎨 عارض ANSI كامل**: 16 لون + 256 لون + Truecolor (RGB) + خلفيات ملونة + غامق/مائل/تسطير/وميض/معكوس/شطب — مع خط طرفية احترافي يدعم Box-Drawing والإيموجي
- **⌨️ كونسول تفاعلي**: شريط إدخال لإرسال نصوص/أوامر للخادم عبر الطرفية — للأدوات والبوتات التي تطلب مدخلات (input / readline) مع صدى للكتابة مثل الترمينال الحقيقي
- **زر Ctrl+C**: إرسال إشارة إيقاف SIGINT عبر الطرفية (0x03) — بالسلوك الحقيقي تماماً
- سجل أوامر بالأسهم (↑/↓) + أزرار نسخ ومسح الكونسول + شارة حالة الطرفية
- تشغيل / إيقاف / إعادة تشغيل + كود الخروج يُسجل تلقائياً

### 🛡️ نظام الحصص
- حد رام لكل مستخدم: مراقبة تلقائية لكل عملية — عند التجاوز يتم إيقافها فوراً مع رسالة في السجل
- حد مساحة تخزين لكل مستخدم: مفروض على الرفع والحفظ والنسخ وفك الضغط
- الأدمن بلا حدود افتراضياً (-1) ويمكنه التخصيص

### 📁 إدارة ملفات شاملة
- مجلدات فرعية كاملة مع مسار تنقل (Breadcrumb)
- رفع ملفات متعددة بالسحب والإفلات
- **📦 فك ضغط مباشر (الافتراضي)**: الملفات تُستخرج مباشرة في المجلد الحالي — بدون مجلد باسم الأرشيف، مع حل تعارض الأسماء تلقائياً (file-1.txt)
- خيار «مجلد جديد» التقليدي + **حذف الأرشيف بعد فك الضغط** — من مودال خيارات واضح
- **فك ضغط تلقائي بعد الرفع** (ZIP / TAR / TAR.GZ / TAR.BZ2 / XZ / 7Z / RAR) — استخراج مباشر في نفس المجلد
- فك ضغط متعدد: حدد عدة أرشيفات وفكها دفعة واحدة
- **↔️ نظام نقل محترف**: منتقى مجلدات بصري (شجرة) + نقل متعدد + خيار استبدال العناصر + سحب وإفلات على المجلدات وفوق مسار التنقل
- ضغط المحدد في ZIP
- تحميل ملف أو مجلد كامل (يضغط تلقائياً)
- نسخ / نقل / تكرار / إعادة تسمية / حذف فردي أو جماعي
- **⚡ تحديد الملف الرئيسي بصرياً**: منتقى شجرة الملفات مع شارة «قابل للتشغيل» + زر ⚡ سريع بجانب كل ملف .py/.js + كشف تلقائي (main.py / index.js / bot.py...) عند التشغيل إذا لم تحدده
- محرر أكواد مباشر (Ctrl+S للحفظ)
- تثبيت المكاتب بزر واحد (pip / npm)

### 📱 متجاوب بالكامل + PWA
- شريط تنقل سفلي ثابت للهواتف (الرئيسية / الكونسول / الملفات)
- كروت إحصائيات بعمودين + أزرار تحكم بصف واحد على الشاشات الصغيرة
- المودالات تفتح كـ Bottom-Sheet من أسفل الشاشة (تجربة تطبيقات الهاتف الأصلية)
- منع الزوم التلقائي في iOS + دعم safe-area للهواتف ذات النوتش
- عند فتح الكيبورد في الكونسول تتغير مساحة الشاشة تلقائياً (interactive-widget)
- **تثبيت اللوحة كتطبيق على الهاتف** (أضف إلى الشاشة الرئيسية) عبر دعم PWA

## 🚀 النشر على Railway

المشروع جاهز للنشر على Railway مباشرة — ملف `Dockerfile` يُكتشف تلقائياً ويبني صورة **Python 3.11 + Node.js 20** معاً.

### الخطوات
1. ارفع المشروع إلى مستودع GitHub
2. في Railway: **New Project → Deploy from GitHub repo**
3. Railway سيبني الصورة تلقائياً ويوفر متغير `PORT` — التطبيق يقرأه ويستمع عليه
4. (اختياري لكن مُوصى به) للحفاظ على الحسابات والخوادم بعد إعادة النشر:
   - **Settings → Volumes → New Volume** واربطه بالمسار `/data`
   - الصورة مضبوطة مسبقاً على `DATA_DIR=/data`
5. (اختياري) أضف متغيرات البيئة من **Settings → Variables**:

| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| `ADMIN_USERNAME` | اسم حساب المسؤول | `Ziad555` |
| `ADMIN_PASSWORD` | كلمة مرور المسؤول | `Ziad555` |
| `SECRET_KEY` | مفتاح ثابت = بقاء الجلسات بعد إعادة التشغيل | عشوائي مؤقت |
| `DATA_DIR` | مكان تخزين بيانات المستخدمين | `/data` (في Docker) |

> ⚠️ غيّر بيانات الأدمن فوراً بعد أول تسجيل دخول، ويفضَّل ضبطها من متغيرات البيئة قبل أول نشر.

### التشغيل محلياً
```bash
pip install -r requirements.txt
python app.py          # يعمل على PORT أو 8080 افتراضياً
```

الحساب الرئيسي: `Ziad555` / `Ziad555` (غيّرها فوراً)

### النشر على Vercel
`vercel.json` يشير إلى `bot.py` (نسخة مطابقة من `app.py`) — ملاحظة: Vercel بيئة Serverless لا تدعم تشغيل خوادم مستمرة، لذا **Railway هو الخيار المُوصى به** للاستضافة الفعلية.

## 🐳 تشغيل Docker محلياً
```bash
docker build -t gojgui .
docker run -p 8080:8080 -v gojgui_data:/data gojgui
```

- ↔️ نظام النقل أُعيد بناؤه: منتقى مجلدات بصري + نقل متعدد + استبدال اختياري + سحب وإفلات
